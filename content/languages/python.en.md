## Design Intent

Python is a high-level, dynamically typed language designed for readability, rapid prototyping, and software expressiveness.

## Key Features

- **Type System:** Dynamic typing with optional static verification via type hints and tools like `mypy`.
- **Runtime & GIL:** CPython reference implementation and the Global Interpreter Lock model.
- **Ecosystem:** Rich ecosystem including PyTorch, TensorFlow, NumPy, FastAPI, and Django.
