## Propósito de Diseño

Python es un lenguaje de alto nivel y tipado dinámico diseñado para la legibilidad, la creacion rápida de prototipos y la expresividad del software.

## Características Clave

- **Sistema de Tipos:** Tipado dinámico con verificación estática opcional mediante type hints y herramientas como `mypy`.
- **Tiempo de Ejecución y GIL:** Implementación de referencia CPython y el modelo Global Interpreter Lock.
- **Ecosistema:** Amplio ecosistema que incluye PyTorch, TensorFlow, NumPy, FastAPI y Django.
