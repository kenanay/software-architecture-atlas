## Design Intent

TypeScript is engineered to bring compile-time static type checking, rich editor tooling, and safe refactoring to large-scale JavaScript applications.

## Key Features

- **Structural Typing:** Shape-based duck typing matching objects by structure.
- **Zero Runtime Overhead:** Erasing all type annotations during compilation to emit clean ECMAScript.
